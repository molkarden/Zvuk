# Живой звук — афиша концертов

Статический сайт-афиша: Москва, Санкт-Петербург, Тула, Калуга, Воронеж, Екатеринбург.
Это учебный проект. Сайт **не продаёт билеты**: кнопка на странице концерта ведёт на Афиша.ру.

Сайт собирается скриптом `build.py` (Python 3.10+) из файла `data/events.json`.
Выходные файлы — обычный HTML/CSS/JS, сервер не нужен.



## Как добавить или обновить концерты

Все концерты лежат в `data/events.json`. Один концерт — один объект:

```json
{"artist":"Pharaoh","tour":"","genre":"hip-hop","city":"moskva",
 "venue":"ВТБ Арена","vt":"stadiony","date":"2026-11-19","time":"20:00",
 "price":5500,"age":"16+","url":"https://www.afisha.ru/concert/pharaoh-6028796/"}
```

| Поле | Значения |
|---|---|
| `genre` | `rok`, `hip-hop`, `klassika`, `dzhaz`, `pop`, `indi`, `elektronika` |
| `city` | `moskva`, `sankt-peterburg`, `tula`, `kaluga`, `voronezh`, `ekaterinburg` |
| `vt` (тип площадки) | `kluby`, `kontsertnye-zaly`, `stadiony`, `open-air` |
| `time`, `price`, `age`, `tour` | необязательные: `null` или пустая строка, если данных нет |

Правила: берите данные только с официальной страницы продавца, ничего не придумывайте
(неизвестное оставляйте пустым) и обновляйте поле `checked` в начале файла.
Жанры, города и типы площадок без концертов на сайте автоматически не показываются.

## Структура

```
build.py            генератор сайта
data/events.json    данные о концертах
src/style.css       стили
src/app.js          фильтры афиши и мелкие скрипты
.github/workflows/  автоматическая публикация на GitHub Pages
```

Необязательные переменные окружения: `SITE_URL`, `BUILD_DATE`, `YM_ID` (Яндекс Метрика),
`YANDEX_VERIFY` (подтверждение в Вебмастере). Описание — в начале `build.py`.

## Важно

- Данные о концертах взяты с Афиша.ру и сверены 13.11.2026; даты и цены меняются.
- Названия артистов и площадок принадлежат их владельцам, проект с ними не связан.
- Постеры на сайте — сгенерированные абстрактные картинки, а не официальные афиши.
